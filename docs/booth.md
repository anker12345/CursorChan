## 商品説明（ここから下を貼り付け）

```
マウスカーソルを、ギャラリーから選んでワンクリックで着せかえ！
Windows 用の無料アプリ「カーソルちゃん」です。

配布されているカーソルの zip をウィンドウに落とすだけで取り込めて、
ダブルクリックですぐに切り替わります。再起動も管理者権限もいりません。

━━━━━━━━━━━━━━━━━━━━
★ できること
━━━━━━━━━━━━━━━━━━━━

◆ ギャラリーで一覧表示
　Windows に入っているカーソル、登録済みのカーソル、取り込んだセットをカードで並べて表示します。
　アニメーションカーソル（.ani）も、ちゃんと動いて見えます。

◆ ワンクリックで着せかえ
　カードをダブルクリックするだけ。すぐに切り替わります。

◆ ドロップで取り込み
　zip・フォルダー・install.inf・.cur・.ani をウィンドウに落とすだけ。
　install.inf がないカーソルでも、ファイル名から「通常の選択」「リンクの選択」などを自動で判別します。
　日本語のファイル名の zip にも対応しています。

◆ 役割ごとに差し替え
　「通常の選択」「テキスト選択」「待ち状態」など 17 種類を、1 つずつ好きなカーソルに入れ替えられます。

◆ 画像からカーソルを作る
　PNG などの画像を選んで、クリックが反応する点（矢印なら先端）を指定するだけでカーソルになります。
　いくつかの大きさをまとめて入れるので、カーソルを大きくしてもきれいです。

◆ サイズ変更・元に戻す
　カーソルの大きさ（32〜256 px）をスライダーで変えられます。
　「既定に戻す」ボタンで、いつでも Windows 標準のカーソルに戻せます。

━━━━━━━━━━━━━━━━━━━━
★ 動作環境
━━━━━━━━━━━━━━━━━━━━

Windows 10 / 11（64 bit）
インストール不要（zip を展開して CursorChan.exe を起動するだけ）

━━━━━━━━━━━━━━━━━━━━
★ 使い方
━━━━━━━━━━━━━━━━━━━━

1. zip をダウンロードして、好きな場所に展開します
2. CursorChan.exe を起動します
3. カーソルの zip やフォルダーをウィンドウに落として取り込みます
4. カードをダブルクリックすれば着せかえ完了！

━━━━━━━━━━━━━━━━━━━━
★ はじめて起動するとき
━━━━━━━━━━━━━━━━━━━━

個人で作っているアプリのため、コード署名をしていません。
初回起動時に「Windows によって PC が保護されました」と表示されることがあります。
その場合は「詳細情報」→「実行」を押すと起動できます。

━━━━━━━━━━━━━━━━━━━━
★ ご注意
━━━━━━━━━━━━━━━━━━━━

・取り込んだカーソルは、それぞれの作者さんの利用規約に従って使ってください。
・このアプリにはカーソル素材は付属していません（Windows 標準のカーソルと、お手持ちのカーソルを使います）。
・Windows の設定で「マウスポインターの色」をカスタムにしていると、そちらの色が優先されることがあります。
・取り込んだセットは %LOCALAPPDATA%\CursorChan\Library に保存されます。
　アプリを削除するときは、先に「既定に戻す」を押してから、このフォルダーも消してください。
```
